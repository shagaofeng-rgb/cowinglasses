# CoWin asset replacement map

`images/demo/hero-glasses.png` and `images/demo/cyclist-glasses.png` are original, generated demo assets used only until approved product and lifestyle materials arrive.

Replace product images in `src/data/fixtures/products.ts` by updating each SKU `images` array and `heroImage`. Keep image dimensions and use Next Image `sizes` values already provided by the components. Place production videos under `public/videos/` and add a SKU `video` path when available.

Do not use the demo images as evidence of real product specs, physical design, performance, certification, or packaging.

`images/payment-methods/` contains the current colour payment-brand assets supplied through Oceanpayment's designated download centre. Their display order is Visa, Mastercard, Maestro, JCB, American Express, Diners Club and Discover. Only display payment methods enabled for the merchant account.
